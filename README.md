
🏥 Patient Management System

A RESTful Patient Management System built using FastAPI and Python to manage patient records. The project also integrates a machine learning model to predict disease risk based on patient information.

 Features

- Create patient records
- Retrieve patient information
- Update patient records
- Delete patient records
- RESTful API endpoints
- Patient data validation
- Disease risk prediction using Machine Learning
- JSON-based patient data storage
- API documentation using FastAPI

 🛠️ Technologies Used

- Python
- FastAPI
- Pydantic
- Machine Learning
- Scikit-learn
- Streamlit
- JSON
- Uvicorn
- REST API
